# Taiyin 中文文档

状态：当前说明
最后更新：2026-08-11

这个目录提供 Taiyin 当前功能和运行时设计的中文说明。文档面向使用者、集成者和后续维护者，优先解释“能做什么、如何调用、有哪些约定和边界”。

阅读建议：

- 想了解整体结构，先看 [`index.md`](index.md)。
- 想接入运行时，先看 runtime、catalog/cache 和 OPC 文档。
- 想调用事件、日月食、恒星相关功能，直接看对应主题文档。
- API 名称、flag、结构体、路径和代码块保留英文，方便和源码对应。
- `current_limitations.md` 记录面向使用者的能力边界和数据要求。
