# Taiyin Documentation

Status: Current
Last updated: 2026-08-11

This directory provides English documentation for Taiyin's current features and runtime design. The documents are written for users, integrators, and future maintainers, with emphasis on what the runtime can do, how it is called, and which conventions and boundaries apply.

Recommended reading:

- Start with [`index.md`](index.md) for the overall structure.
- For runtime integration, read the runtime, catalog/cache, and OPC documents first.
- For event, eclipse, or star-related APIs, read the corresponding topic document directly.
- API names, flags, structs, paths, and code blocks remain in English so they map directly to the source code.
- `current_limitations.md` records user-visible capability boundaries and data requirements.
